# Canvas Melodies

Интерактивное веб-приложение, где пользователь рисует линии на экране (canvas), и каждая линия мгновенно воспроизводит музыкальный звук. Позиция, длина и угол линии определяют высоту ноты, длительность и тембр.

This project was built with [Lovable](https://lovable.dev).
